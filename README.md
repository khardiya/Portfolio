# Bablu Arya —Portfolio

A responsive portfolio built with plain HTML, CSS and JavaScript. No React, Vite, npm install, or build step is required.

## Run locally
Open `index.html` in your browser, or use VS Code Live Server.

## GitHub Pages
1. Put `index.html`, `style.css`, `script.js`, and the `assets` folder in the repository root.
2. In GitHub → Settings → Pages, select the `main` branch and `/ (root)` as the source (or GitHub Actions if using a workflow).
3. The site uses relative asset paths, so it works at `https://khardiya.github.io/Portfolio/`.

## Update content
- Projects and links: edit the project cards in `index.html`.
- Certificates: all cards currently open the LinkedIn certifications page. Replace each with its individual credential URL if you want direct verification.
- Contact form: uses a `mailto:` link and opens the visitor's email application; it does not send messages through a server.
- Profile image: replace `assets/me.jpeg`.
